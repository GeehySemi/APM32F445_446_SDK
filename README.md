# APM32F445_446_SDK
Official software development kit for Geehy APM32F445/APM32F446 microcontrollers.

## Current version

- SDK version: V1.0.0
- Supported device: APM32F445，APM32F446
- Official package date: 08-September-2026
- Release notes date: October 27th, 2026
- Official download: [APM32F445_446_SDK_V1.0.0.zip](https://www.geehy.com/uploads/tool/APM32F445_446_SDK_V1.0.0.zip)

## Supported development environments
The package includes projects and resources for Keil MDK, IAR Embedded Workbench, and Eclipse/GCC, together with CMSIS, peripheral libraries, middleware, board support, and examples.
