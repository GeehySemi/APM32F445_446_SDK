&par Example Description

The purpose of this demo application is to show you how to use the LPUART with DMA
from the APM32F445 MCU using the SDK.

You need to connect a serial console to UART1. The application will print a
brief message describing the example behavior at startup. Then you can input a
string and press ENTER. It will echo back any string that is sent from the console.
If 'Hi,Geehy\n' are sent, the board will reply with 'Welcome'.

&par Hardware Description
The following connections must be done to for this example application to work:

LPUART1 is configured as follows:
    - TX:PC7, RX:PC6
    - BaudRate = 115200 baud
    - Word Length = 8 Bits
    - One Stop Bit
    - No parity
    - Hardware flow control disabled (RTS and CTS signals)
    - Transmit enabled
