&par Example Description
The purpose of this demo application is to show you how to use the
Analog Comparator of the APM32F445 MCU using the SDK API.

The Comparator is configured to compare analog input 0 (AIN0) with 1/3 of the
reference voltage generated by the internal DAC. Based on the input voltage,
the LEDs light according the following rules:
  - Vin < DAC voltage : RED on, GREEN off
  - Vin > DAC voltage : RED off, GREEN on
  - Unknown state : RED on, GREEN on

&par Hardware Description

APM32F445_EVAL
LED_RED (PTD0)
LED_GREEN (PTD15)
CMP Input 0 (PTA0)
