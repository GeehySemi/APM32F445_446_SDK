&par Example Description

This example describes how to use the memory protection function of the MPU.
Press the KEY1 will read data in the protected memory, it will trigger a
memory error, if the error information is the same as the expected, the
LED will change from green to red.

&par Hardware Description

KEY1: PC12

&par IDE environment

&par Hardware and Software environment

  - This example runs on APM32F445 EVAL Devices.
